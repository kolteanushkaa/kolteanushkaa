## 🚀 Projects

### 🔹 Customer Churn Prediction
Built a supervised machine learning pipeline using **Logistic Regression, Random Forest, and XGBoost** to predict customer churn. Applied EDA, feature engineering, and SMOTE for imbalanced data.

### 🔹 Aircraft Damage Classification & Captioning
Developed a computer vision solution using **CNN and VGG16 Transfer Learning** to classify aircraft damage from images.

### 🔹 Customer Support Chatbot
Currently developing a **hybrid NLP + LLM customer-support chatbot** using FAQ retrieval, TF-IDF, cosine similarity, and an LLM fallback. Exploring **embeddings and RAG** for semantic retrieval and domain-specific responses.

### 🔹 Netflix Content Analytics
Analyzed **8,807 Netflix titles** and built an interactive **Power BI dashboard** using DAX and Power Query to identify content and geographic trends.
